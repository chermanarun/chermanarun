## Featured projects

### [SecureShare](https://github.com/chermanarun/SecureShare)
A reference application for secure document sharing across multiple tenants. It separates identity, authorization, and delegated access, with relationship-based permissions and temporary read tokens.

**Built with:** Python · FastAPI · OpenFGA · PostgreSQL · Docker

[Explore the code](https://github.com/chermanarun/SecureShare) · [Architecture](https://github.com/chermanarun/SecureShare/blob/main/docs/architecture.md) · [Threat model](https://github.com/chermanarun/SecureShare/blob/main/docs/threat-model.md)

### [CWE Intelligence & Remediation Engine](https://github.com/chermanarun/cwe-lookup)
